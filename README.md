To check that Java is installed, run:

How to use the repository
1. Download or clone the repository.
2. Extract CSA09_Assignment1_Solutions.zip if you are using the ZIP archive.
3. Open the folder for the task you want to work on.
4. Read that task's Answer.md or other notes, if provided.
5. Compile and run the Java source files for that task. Use the class containing public static void main(String[] args) as the entry point, if the task includes one.
6. Compare the program output with any expected-output notes included in the task folder.
Compile and run a Java file
From a terminal opened in the relevant task folder:
javac Main.java
java Main
Replace Main.java and Main with the actual filename and class name for that task. If a task contains several Java files, compile them together, for example:
javac *.java
Then run the class that contains the main method. Follow any task-specific instructions in that folder.
