Task 1: Problem Understanding
Aim
To understand the requirements of the Campus Smart-Parking System before developing the program.
Description
The Campus Smart-Parking System is designed to manage parking spaces inside a college campus. It stores vehicle details, allocates parking slots, records entry and exit times, and calculates parking fees.

The main classes required for this system are Vehicle, ParkingSlot, ParkingTicket and ParkingFacility.
Inputs
- Vehicle registration number
- Vehicle type
- Entry and exit time
- Number of parking floors and slots
Outputs
- Allocated parking slot
- Parking ticket details
- Parking fee
- Availability of parking spaces
Conclusion
This task helped me understand the problem and identify the main classes and functions needed for the parking system.
