# Task 2: Data Representation

## Aim
To select suitable Java data types and data structures for storing parking information.

## Description
Different data types are used depending on the information being stored.

- `String` stores vehicle registration numbers.
- `int` stores floor numbers and slot indexes.
- `LocalDateTime` stores entry and exit times.
- Arrays store parking slot information.
- Decimal values are used for calculating parking fees.

A two-dimensional or jagged array can represent parking floors with different numbers of slots.
