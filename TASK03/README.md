# Task 3: Parking Facility and Control Logic

## Aim
To implement the logic for allocating and releasing parking slots.

## Description
The `ParkingFacility` class manages the available parking spaces. The program checks the slots one by one and allocates the first available slot.

If all slots are occupied, the method returns `null`. When a vehicle leaves, its slot can be released for another vehicle.

## Concepts Used
- Arrays
- Loops
- Conditional statements
- Methods
- Boolean values

## How to Run
```bash
javac ParkingFacility.java
java ParkingFacility
```

## Expected Output
```text
[0, 0]
[0, 1]
[1, 0]
null
true false false
[0, 1]
```
