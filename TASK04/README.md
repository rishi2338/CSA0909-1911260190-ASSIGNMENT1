# Task 4: Classes, Objects and Constructors

## Aim
To understand how classes, objects and constructors are used in Java.

## Description
A class defines the properties and methods of an object. An object is created from a class.

Constructors initialise objects when they are created. Parameterised constructors allow values to be passed during object creation.

The `this` keyword refers to the current object, while `super()` is used to call a parent-class constructor.

## Concepts Used
- Classes and objects
- Constructors
- `this` keyword
- `super()` keyword
- Input validation
