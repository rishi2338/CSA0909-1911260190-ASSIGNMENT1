# Task 5: Static Members and Object Life Cycle

## Aim
To understand static variables, instance variables and the life cycle of objects in Java.

## Description
A static variable belongs to the class and is shared by all objects of that class. An instance variable belongs to an individual object.

In the parking system, a static counter can be used to generate ticket numbers. Each ticket object stores its own information.

Java garbage collection can remove objects that are no longer reachable, but the exact time of garbage collection is not guaranteed.

## Concepts Used
- Static variables
- Instance variables
- Object creation
- Garbage collection

## Conclusion
This task helped me understand the difference between class-level data and object-level data.
