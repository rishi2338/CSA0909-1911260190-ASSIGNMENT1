# Task 6: Inheritance Hierarchy

## Aim
To demonstrate inheritance using different vehicle types in the parking system.

## Description
The `Vehicle` class acts as a common parent class. Different vehicle types inherit its common properties and behaviour.

Examples include:
- `TwoWheeler`
- `Car`
- `ElectricCar`
- `EBike`
- `DeliveryVan`

The child classes can reuse common information such as the registration number while adding their own behaviour.

## Concepts Used
- Inheritance
- Parent and child classes
- Code reuse
- `extends` keyword

## Conclusion
This task helped me understand how inheritance reduces repeated code and organises related classes.
