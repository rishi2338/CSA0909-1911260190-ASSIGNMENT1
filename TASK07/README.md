# Task 7: Method Overriding and Equality

## Aim
To understand method overriding and how Java objects can be compared.

## Description
Different vehicle classes can override the `parkingFee()` method to calculate fees according to their vehicle type.

The `@Override` annotation indicates that a method is intended to override a parent-class method.

The `equals()` method can compare vehicles using their registration numbers. The `hashCode()` method should follow the same equality rule.

## Concepts Used
- Method overriding
- `@Override`
- `equals()`
- `hashCode()`

## Conclusion
This task helped me understand how different vehicle classes can implement the same method differently and how objects can be compared.
