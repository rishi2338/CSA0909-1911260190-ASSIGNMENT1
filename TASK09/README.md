# Task 9: Abstraction and Interfaces

## Aim
To understand abstraction and interfaces in Java.

## Description
An abstract class provides common features for related classes but cannot be instantiated directly.

In the parking system, `Vehicle` can be an abstract class. Specific vehicle classes provide their own parking-fee calculations.

The `Chargeable` interface represents vehicles that support charging. An `ElectricCar` can implement this interface.

## Concepts Used
- Abstract classes
- Abstract methods
- Interfaces
- `implements` keyword

## Conclusion
This task helped me understand how abstraction reduces unnecessary details and how interfaces define capabilities that classes can implement.
