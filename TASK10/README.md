# Task 10: Packages and Encapsulation

## Aim
To understand how packages organise Java classes and how encapsulation protects data.

## Description
Packages help organise related classes in a project. The integrated parking program uses the `parking` package.

Encapsulation is implemented by making fields private and accessing them through suitable methods. Validation can be added to prevent invalid values from being stored.

Wrapper classes such as `Integer` allow primitive values to be used in collections.

## Concepts Used
- Packages
- Access modifiers
- Private fields
- Getter and setter methods
- Wrapper classes

## Conclusion
This task helped me understand how packages organise code and how encapsulation protects important information.
