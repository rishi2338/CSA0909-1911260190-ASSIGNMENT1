# Task 11: Integrated Parking System

## Aim
To combine the main components into a working Campus Smart-Parking System.

## Description
The integrated program combines vehicle classes, parking slots, tickets and parking-fee calculations.

It demonstrates parking different types of vehicles, checking fees, handling passes and releasing occupied slots.

The example parking rates are assumptions used for demonstration purposes.

## How to Run
Open a terminal in the Task11 folder and execute:

```bash
javac -d out src/parking/ParkingSystemDemo.java
java -cp out parking.ParkingSystemDemo
```

## Expected Output
The program displays the allocated tickets, vehicle details, parking fees, total collected amount and remaining active tickets.

The exact output should be checked against the version of `ParkingSystemDemo.java` included in the project.

## Testing
The program should be tested with different vehicle types, occupied slots, parking passes and vehicle exits.

## Conclusion
This task helped me understand how multiple Java classes work together to solve a practical problem.
